BambuLED

拓竹打印机状态联动灯带配置中心。通过下面 3 个菜单切换配置区域，随时调整 WiFi、打印机 MQTT 和灯光参数。

WiFi 配置

填写家庭或工作室的 2.4GHz WiFi 信息，保存后设备会自动尝试联网。

未连接

当前未连接到路由器

设备会持续开启配置热点，你也可以在这里填写家里或工作室的 WiFi 信息。

这里只会提交 WiFi 名称和密码，用于连接或切换路由器。

连接打印机

填写拓竹打印机本地 MQTT 连接信息，用于获取实时状态并自动切换灯效。

高级设置

这里只会保存打印机 MQTT 连接参数，不会修改 WiFi 和灯光设置。

灯光设置

这里可以自定义灯带硬件参数、默认颜色，以及打印机各状态的灯效映射。保存后会持久化到设备，并立即重新应用。

基础参数

先设置灯带硬件和全局亮度，下面每个状态再单独设置颜色、效果和速度。

默认 10 颗，按实际灯带数量填写。
默认 GPIO 1（ESP32-S3 可用到 48），请按你的接线修改。
1-25564
所有灯效都会在这个亮度上运行。
1-25540
新状态如果没单独设置，会回退到这个速度。

状态联动自定义

每种打印机状态都可以单独选择灯效、速度和颜色。打印中建议保留“进度条”，完成建议使用“彩虹流光”。

空闲 / 待机

推荐柔和呼吸灯。

加热中

推荐暖黄色慢闪或渐变。

打印中

推荐使用进度条显示打印进度，也可以改成常亮或流光。

打印完成

推荐彩虹庆祝特效，也可以改成流光或呼吸灯。

打印暂停

推荐橙色呼吸提示。

故障 / 告警 / 断料

推荐红色高频爆闪，用于快速吸引注意。

这里只会保存灯光参数与状态映射，不会影响 WiFi 和打印机连接。
